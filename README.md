## SEO Details

- **Target keyword:** House and Villa Painting Dubai

- **Schema:** LocalBusiness structured data included in `<head>`

## Design

- Theme: Luxury / Premium with animated gold accents
- Color palette: Deep ink black `#0E0E0E` · Gold `#B89A5A` · White
- Fonts: Cormorant Garamond (display) + DM Sans (body)
- Animations: Hero entrance, shimmer lines, floating orbs, scroll reveal
- No phone number or call button included (as requested)
- Fully responsive — mobile + desktop
- Respects `prefers-reduced-motion`
